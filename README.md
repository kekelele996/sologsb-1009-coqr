# 教材无障碍改写工作台

面向教材编辑和特殊教育内容团队的无障碍改写、自动检查、审校与导出工具。项目预置科学教材章节示例并包含真实的待处理问题。

## 功能

- 导入 TXT、Markdown 章节文本；识别 Markdown 标题、图片和单行链接。
- 检查标题层级跳跃、图片替代文本缺失、链接文案不明确、长句和术语不一致。
- 将复杂段落按标点和语义拆为较短的易读表达，并统一术语表中的固定表达。
- 为每个内容块记录改写原因及待审核、已通过、需修改状态。
- 添加批注、回复和解决批注。
- 阅读预览可在普通模式和高对比、大字号辅助模式间切换。
- 以编号列表展示读屏软件从 H1 到正文、图片和链接的阅读顺序。
- 保存最多 10 个版本快照，并并排比较旧版和当前无障碍文本。
- **送审与回稿按段落对账**：导出带隐形段落标记的送审稿并自动留档；教研组回稿导入后按段落与当前草稿三方对账（送审留稿 / 当前草稿 / 回稿）。只有一边动过的段落自动走改动方；两边都改过的段落两版都保留并标出冲突，由编辑逐段挑选一版；教研组新增、删除的段落分别计入对账报告。回稿若不属于当前章节（章节编号不匹配或内容整体对不上），不改动草稿并说明原因，可重新选择文件导入；合并前自动留档「回稿原文」和「合并前草稿」，合并是一次可整体撤销的操作。
- 撤销/重做、自动保存、离线继续编辑。
- 导出完整无障碍 HTML：包含 `lang`、跳转正文链接、语义标题、图片 `alt`、描述性链接、键盘焦点样式和屏幕阅读器可读结构。
- 键盘操作：`J`/`K` 跳转问题，`E` 生成易读版本，`1`/`2` 切换预览模式，`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做，`Ctrl/Cmd+S` 保存版本。

## 技术栈

- Astro 7 + TypeScript
- Shoelace Web Components
- 原生 DOM/CSS 与浏览器 `localStorage`
- 静态 HTML 构建、nginx 容器部署

## 开发

需要 Node.js 22.12 或更高版本。

```bash
npm install
npm run dev
```

## 检查与构建

```bash
npm run check
npm run build
npm run preview
```

`npm run build` 会先执行 Astro 类型/内容检查，再生成 `dist/` 静态产物。

## Docker

容器内 nginx 监听 `80`，宿主端口按根端口映射为 `10009`。

```bash
docker build -t sologsb-1009 .
docker run --rm -p 10009:80 sologsb-1009
```

访问 `http://localhost:10009`。

## 数据说明

章节、改写原因、批注、术语和版本均保存在当前浏览器 `localStorage`。导出的 HTML 是独立文件，不依赖后端，但演示图片使用内嵌 SVG；接入真实教材时应替换为可访问的正式图片地址并复核替代文本。

## 教研组送审与回稿对账流程

1. **送审导出**：点击左侧「送审导出」，下载带隐形段落标记（HTML 注释，含章节编号与送审时间）的 Markdown，发给教研组的同时在「送审与留档」中自动保存一份送审留稿。
2. **教研组回稿**：教研组直接在送审稿上修改文字（可新增、删除、改写段落），无需手工处理标记；即使标记在传阅中被清除，也会按文本相似度兜底对齐。
3. **导入对账**：点击「导入回稿对账」选择回稿文件，系统按段落生成对账报告：仅一边改过的段落自动按改动方处理，两边都改过的段落并列保留两版并默认选中当前草稿，编辑在报告中逐段挑选，也可合并后在每个冲突段落的卡片里再改选。
4. **外来回稿拦截**：章节编号不匹配，或没有标记且内容整体对不上时，草稿不做任何改动，对话框说明具体原因；回稿原文仍会留档，可重新选择文件导入。
5. **留档与撤回**：确认合并前自动保存「回稿原文」和「合并前草稿」两份留档（可下载、可一键恢复）；整次合并是一条撤销记录，合并完成后的提示条或工具栏「撤销」都可整体回退。
